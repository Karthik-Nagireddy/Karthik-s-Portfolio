# Nagireddy Karthik — Portfolio

Personal portfolio site. B.Tech Electrical Engineering, Delhi Technological University (2027).

- Single static page: `index.html` (no build step)
- Live demos: PID step-response tuner and a half-adder logic circuit
- Respects light/dark mode and reduced-motion settings

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / root → Save.
The site will be at `https://karthik-nagireddy.github.io/Karthik-s-Portfolio/`.
